Notifications and scheduled commands

Reminders, task due alerts, and background work use Android notifications. Long jobs (search, sync, speech listening) may show a foreground service notification while they run.

Permissions

On Android 13+, allow Notifications when prompted. Denying notifications hides reminder toasts and status for scheduled work—you can re-enable in system Settings.

Scheduled commands

Open menu → Scheduled commands to review one-shot and repeating jobs created by Help (“remind me to … at …”) or your own Lisp. Each entry shows the next run time and whether it fires a document command or a script.

Best practices

  • Use plain language in Help to create schedules; confirm the summary before saving.
  • For location reminders, complete setup location first.
  • Open App status from the menu if a job seems stuck.
