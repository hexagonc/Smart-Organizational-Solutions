Workspaces

A workspace is a named set of note references for one project or context—Android notes, a trip plan, onboarding docs—without copying files. Switch workspaces from the note editor Tools sheet → Workspace tab.

Add notes to a workspace

  1. Open a note.
  2. Open the Tools sheet → Workspace tab.
  3. Tap W+ to create a workspace or pick an existing one.
  4. Use Add note to workspace (from the same sheet) while editing other notes you want in the set.

Each row shows the note title and collection path. Tap × to remove a reference (the underlying note is not deleted).

Library vs workspace

Library tree Workspace
Purpose Permanent hierarchy Temporary or topical grouping
Scope Whole collection Your chosen list
Search Can search workspace mode See search your notes

Power users manage global collections and post-init scripts under Profile; daily writing usually stays in the Workspace tab on the notes you already have open.
